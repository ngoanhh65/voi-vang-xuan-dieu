# Vội vàng – Xuân Diệu

Website thuyết trình tương tác về bài thơ **Vội vàng**.

## Xem bài thuyết trình
Mở [index.html](./index.html) hoặc bật GitHub Pages:
1. Vào **Settings** của repository.
2. Chọn **Pages**.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn nhánh **main**, thư mục **/(root)** rồi nhấn **Save**.
5. Sau khi xuất bản, trang dự kiến ở: https://ngoanhh65.github.io/voi-vang-xuan-dieu/

## Điều khiển
- Nhấn **MỞ KHU VƯỜN** để bắt đầu.
- Dùng nút **Trước / Tiếp** hoặc phím mũi tên trái/phải.
- Có thể bật/tắt âm thanh nền tổng hợp nguyên bản.

## Nội dung
15 phần: tác giả, tác phẩm, nhan đề, khát vọng níu giữ vẻ đẹp, bức tranh thiên nhiên, cách cảm nhận độc đáo, thời gian, tuổi trẻ, lời giục giã sống, nghệ thuật, so sánh văn học, giá trị và bài học.

*Bài trình bày phân tích tác phẩm, không thay thế văn bản toàn bài thơ trong sách giáo khoa.*
